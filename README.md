# Banking Credit Risk, Repayment Behaviour & Portfolio Analytics

## Project Overview

This project focuses on analysing credit card customer data to understand repayment behaviour and identify patterns associated with credit default.

The analysis uses a historical dataset containing 30,000 customer records. Python, SQL and Excel are used to clean, explore, analyse and visualise the data.

The main objective is to identify customer segments with higher default rates, understand repayment patterns and provide data-driven recommendations to support credit-risk monitoring.

## Project Objectives

1. Understand the credit card customer dataset and its structure.
2. Clean and prepare the dataset for analysis.
3. Analyse customer repayment behaviour and credit default patterns.
4. Identify customer segments with higher default rates.
5. Examine the relationship between credit utilisation and default.
6. Use SQL to perform customer-level and portfolio-level analysis.
7. Create Excel PivotTables, PivotCharts and a dashboard.
8. Generate meaningful business insights and recommendations.

## Dataset Description

**Dataset Name:** Default of Credit Card Clients

**Source:** UCI Machine Learning Repository

**Dataset Link:** https://archive.ics.uci.edu/dataset/350/default

### Dataset Details

- Total Records: 30,000
- Original Columns: 25
- Data Type: Structured tabular data
- Data Domain: Banking and Credit Risk
- Target Variable: `default payment next month`

### Target Variable

- 0 – No Default
- 1 – Default

### Main Data Categories

1. Customer Information – Age, Gender, Education and Marriage.
2. Credit Information – Credit Limit.
3. Repayment Status – Monthly repayment status.
4. Bill Amounts – Monthly bill amounts.
5. Payment Amounts – Monthly payment amounts.
